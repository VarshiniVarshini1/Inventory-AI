# Inventory AI Agent

A complete AI-powered inventory optimization system built with:

- FastAPI Backend
- React Frontend
- PostgreSQL Database
- ML Models (Prophet, XGBoost, LSTM, ARIMA)
- AI Agent using OpenAI

## Features

### 🔹 Inventory Intelligence
- Demand forecasting
- Auto reorder level calculation
- Safety stock computation
- Inventory health score

### 🔹 Supplier Intelligence
- Supplier scoring
- Delivery & defect analysis

### 🔹 AI Agent
- Natural-language chatbot
- Predictive insights
- Purchase order recommendations

### 🔹 Dashboard
- Forecast graphs
- Alerts
- Multi-store support

### 🔹 Notifications
- Email alerts
- WhatsApp alerts
